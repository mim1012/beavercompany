# 비버컴퍼니 (Beaver Company) - 웹사이트 & 마케팅 자동화 시스템

비버컴퍼니는 유치원, 초등학교, 도서관 등 교육기관을 대상으로 **찾아가는 공연 서비스**를 제공하는 전문 업체입니다.

이 레포지토리는 비버컴퍼니의 공식 웹사이트 소스코드와 마케팅 업무 자동화 시스템을 통합 관리합니다.

## 📋 프로젝트 구조

```
beaver-company-website/
├── src/                          # 웹사이트 소스코드
│   ├── index.html               # 메인 웹사이트 HTML
│   ├── components/              # React 컴포넌트 (향후 추가)
│   ├── pages/                   # 페이지 컴포넌트 (향후 추가)
│   └── assets/                  # 이미지, 폰트 등
├── public/                       # 정적 파일
│   └── favicon.ico              # 파비콘
├── docs/                         # 기술 문서
│   ├── ARCHITECTURE.md          # 아키텍처 설명
│   ├── SETUP.md                 # 설치 및 실행 가이드
│   └── DEPLOYMENT.md            # 배포 가이드
├── marketing-automation/         # 마케팅 자동화 시스템
│   ├── README.md                # 마케팅 시스템 매뉴얼
│   ├── content-planning/        # 콘텐츠 기획 시스템
│   ├── blog-templates/          # 블로그 콘텐츠 템플릿
│   ├── sns-strategy/            # SNS 전략 및 가이드
│   ├── competitor-analysis/     # 경쟁사 분석 리포트
│   ├── performance-reports/     # 월간 성과 리포트
│   └── automation-workflows/    # 자동화 워크플로우
├── .gitignore                   # Git 무시 파일
└── README.md                    # 이 파일
```

## 🎯 프로젝트 목표

### 웹사이트
- 비버컴퍼니의 공연 서비스를 효과적으로 홍보
- 사용자 친화적인 인터페이스로 고객 경험 향상
- 모바일 최적화 및 빠른 로딩 속도 보장
- SEO 최적화로 검색 엔진 가시성 확대

### 마케팅 자동화 시스템
- 블로그 콘텐츠 기획 및 초안 생성 자동화 (월 4건)
- SNS 콘텐츠 아이디어 도출 및 전략 수립 (주 1회)
- 경쟁사 모니터링 및 분석 자동화 (주 1회)
- 월간 마케팅 성과 리포트 자동 생성
- 홈페이지 개선 아이디어 지속적 제안

## 📊 기대 효과

- **마케팅 콘텐츠 제작 시간 50% 절감**
- **성과 분석 시간 70% 절감**
- **콘텐츠 품질과 일관성 향상**
- **온라인 가시성 및 브랜드 인지도 향상**

## 🔧 기술 스택

### 웹사이트
- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: React 18 (향후 마이그레이션 예정)
- **Styling**: TailwindCSS (향후 적용)
- **Build Tool**: Vite (향후 적용)
- **Package Manager**: npm

### 마케팅 자동화
- **문서 형식**: Markdown
- **버전 관리**: Git/GitHub
- **분석 도구**: Google Analytics, 네이버 애널리틱스
- **자동화 도구**: 웹 스크래핑, API 연동

## 📈 마케팅 성과 지표

### 3개월 단기 목표
- 블로그 월간 방문자: 5,000명 → 7,500명 (50% 증가)
- SNS 팔로워: 현재 대비 300명 증가
- 월간 문의 건수: 현재 대비 30% 증가
- 주요 키워드 상위 노출: 10개 키워드 상위 10위 진입

### 6개월 중기 목표
- 블로그 월간 방문자: 10,000명 달성
- SNS 팔로워: 현재 대비 500명 증가
- 문의 전환율: 3% 달성
- 브랜드 인지도: 온라인 언급량 50% 증가

## 📝 콘텐츠 전략

### 블로그 콘텐츠
- **공연 후기**: 실제 공연 현장 스토리와 고객 반응
- **교육 가이드**: 교육기관 담당자를 위한 실용적 정보
- **비하인드 스토리**: 비버선생님의 공연 노하우 공유
- **계절별 특집**: 시즌에 맞는 공연 아이디어

### SNS 전략
- **유튜브**: 공연 영상, 쇼츠, 교육 콘텐츠
- **인스타그램**: 공연 현장 사진, 릴스, 스토리
- **네이버 포스트**: 블로그 콘텐츠 연동, 카드뉴스
