## 3. 제공 서비스 분석

### 3.1 공연 종류
1. **인형극** - 교육적 메시지와 상상력을 담은 참여형 공연
2. **마술쇼** - 신기한 마술로 놀라움과 환상을 선사
3. **솜사탕쇼** - 캐릭터 솜사탕으로 즐거움 제공 (인기 공연)
4. **버블쇼/풍선쇼** - 환상적인 버블과 풍선 퍼포먼스
5. **운동회** - 비버선생님 직접 진행하는 안전한 운동회
6. **음향/조명 렌탈** - 고품질 음향과 조명 시스템 제공
7. **샌드아트** - 모래로 그려내는 감성적인 퍼포먼스
8. **복합 공연** - 다양한 공연을 조합한 맞춤형 서비스

### 3.2 공연 특징
- 공연 시간: 20~50분 (프로그램에 따라 조정 가능)
- 장소: 실내/야외 구분 없이 가능 (아파트 거실~대강당)
- 진행자: 전병규 선생님 직접 진행
- 준비물: 모든 장비와 준비물 업체에서 제공
